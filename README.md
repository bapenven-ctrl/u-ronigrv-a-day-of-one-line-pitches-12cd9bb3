# A Day of One-Line Pitches

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3)
[![competition](https://img.shields.io/badge/competition-u--ronigrv--a--day--of--one--line--pitches--12cd9bb3-green)](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3)

Entry for make.fun's **A Day of One-Line Pitches** bounty ($5, 3 places).
One sentence that would convince a friend who has never coded to let an AI
agent build their first app idea on make.fun.

## Run

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt` (UTF-8, 153 characters, no trailing
newline). Deterministic: two runs produce byte-identical output.
Standard library only, no network.
